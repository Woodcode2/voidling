- THE MAGNET, not the spawn, is the story of the fourth finding. The reviewer attributed the eat to a prop standing where the clearance scan should have caught it; the code says the well's reach for a small prop is ~3 units against 2.1 measured, and the pull runs through the intro with no condition. The face even turns HUNGRY at `d < reach*0.85` (9402) — in maple_u0_canvas.png the void's eyes are on the box. A one-condition gate closes it; a spawn nudge is a guess.
- THE FRAMES' CARD TIMING IS OFF THE CODE BY ~0.8 s (no card at u75/0.88 s where the CSS says opaque from 0.59 s; a ghost at u0/2.59 s where the CSS says opaque to 3.02 s). Whatever the cause (wall-vs-match under swiftshader), any gate that reads card opacity at a fixed match-time is unreliable — assert geometry (rects) or read the live computed opacity, never assume the phase from `tPage`.

The upper-third move fixes it for free; worth saying so, because it is a second reason for the same change.
